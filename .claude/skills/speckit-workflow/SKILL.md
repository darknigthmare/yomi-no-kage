# Spec Kit workflow

Check AGENTS.md, existing specs, plans, tasks, decisions, and `.ai-tools/README.md` first. If `.specify/` exists, inspect its actual installed scripts, commands, hooks and extensions before invoking any `speckit-*` skill. If `.specify/` does not exist, do not invoke missing commands or silently initialize Spec Kit. Use ordinary spec/plan/tasks documents, or propose optional setup from https://github.com/github/spec-kit if appropriate and authorized. Preserve project-specific Spec Kit commands; this is guidance, not a CLI installation.
